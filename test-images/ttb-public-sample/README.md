# TTB Public COLA Sample

This fixture set contains 50 public COLA submissions downloaded from the TTB Public COLA Registry.

- Search date window: 06/01/2026 through 06/08/2026
- Submission folders: 50
- Label images: 80
- Histogram:
  - 1 image: 22 submissions
  - 2 images: 26 submissions
  - 3 images: 2 submissions

Each submission folder includes:

- `metadata.json`: source URL, TTB ID, registry row metadata, image count, and image filenames.
- `detail.html`: the public printable COLA detail page used to extract label attachments.
- downloaded label image files.

`index.json` contains the full sample manifest.
